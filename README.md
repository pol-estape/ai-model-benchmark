# AI Model Benchmark Platform

A Python application for benchmarking and comparing
the performance of Large Language Models (LLMs).

## Objectives

- Benchmark local LLMs using Ollama
- Measure response time and tokens per second
- Evaluate answer accuracy
- Store historical benchmark results
- Visualize performance using a dashboard

## Technologies

- Python
- Ollama
- FastAPI
- Streamlit
- SQLite
- Pandas
- Plotly
